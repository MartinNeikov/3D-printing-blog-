# 3D Printing Blog

> React project developed for the **SoftUni ReactJS Regular Exam 2026**.

A community-oriented blog focused on **3D printing**, including topics such as:

- 3D printers
- Filaments
- Print settings
- Projects
- Troubleshooting
- Guides
- Reviews

---

## 📌 Current Project Status

The project is currently in its **UI and component structure stage**.

### ✅ Implemented so far

- React project created with **Vite**
- **ESLint** configured
- Blogy HTML template converted to **JSX**
- `Header` extracted into a reusable React component
- `Footer` extracted into a reusable React component
- `Home` extracted into a separate page component
- Reusable article components created
- Reusable section header component created
- Home page content started to be adapted to a **3D printing theme**
- External template CSS integrated into the React project
